# Azeez Hamzat

The source for [azeezhamzat.com](https://azeezhamzat.com), a research and writing website focused on collective intelligence, group decision-making, agricultural knowledge systems, and human-AI interaction.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Articles live in `src/content/writing` as Markdown files. The site is built with Astro and published through GitHub Pages.
